# قهرمان جدول ضرب (Zarb Hero)

اپلیکیشن کامل، آفلاین و کودک‌پسند برای آموزش و سنجش جدول ضرب ویژه کودکان ۹ تا ۱۲ سال به زبان فارسی.

## تغییرات نسخه جدید:
- **تغییر نام خروجی به Jadval_Zarb.apk:** نام فایل نصبی منتشر شده در بخش Release گیت‌هاب و Artifacts به `Jadval_Zarb.apk` تغییر یافت.
- **حذف ضرایب ساده ۱، ۲ و ۱۰:** تمام سؤالات به‌صورت اختصاصی و متمرکز از اعداد ۳ تا ۹ انتخاب می‌شوند (۲۸ ترکیب یکتا بدون تکرار معادل).
- **تنظیم آیکون و لوگوی اختصاصی:** لوگوی اختصاصی کودکانه در تمام رزولوشن‌ها تعبیه شده است.
- **حذف دکمه‌های بازگشت مضاعف بالای صفحات:** تنها دکمه اصلی و بزرگ پایین صفحه برای بازگشت استفاده می‌شود.
- **گزارش روزانه فعالیت (کنترل والدین):** در بخش سوابق، جدولی بر اساس تاریخ میلادی اضافه شده که تعداد آزمون‌ها و جمع درستی و خطاهای هر روز را نمایش می‌دهد.

## اتوماسیون انتشار نسخه (Automated Releases):
گردش‌کار GitHub Actions با مجوز `contents: write` و برچسب‌های `v*` پیکربندی شده است.
هر بار که یک Tag مانند `v1.3.2` ثبت کنید یا از بخش Releases گیت‌هاب دکمه **Draft a new release** را با تگ دلخواه بزنید، پروژه به‌صورت خودکار کامپایل و تست شده و فایل با نام `Jadval_Zarb.apk` مستقیماً در بخش Releases منتشر خواهد شد.
