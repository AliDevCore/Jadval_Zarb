# قهرمان جدول ضرب (Zarb Hero) - نسخه ۱.۱.۰

اپلیکیشن کامل، آفلاین و کودک‌پسند برای آموزش و سنجش جدول ضرب ویژه کودکان ۹ تا ۱۲ سال به زبان فارسی.

## تغییرات نسخه جدید (v1.1.0):
- **حذف ضرایب ساده ۱، ۲ و ۱۰:** تمام سؤالات به‌صورت اختصاصی و متمرکز از اعداد ۳ تا ۹ انتخاب می‌شوند (شامل ۲۸ ترکیب یکتا بدون تکرار معادل).
- **بهبود ناوبری و دکمه‌های بازگشت:**
  - اضافه شدن دکمه بازگشت در نوار بالای صفحه کارنامه.
  - اضافه شدن دکمه بزرگ «بازگشت به صفحه اصلی 🏠» به انتهای صفحه کارنامه.
  - پشتیبانی کامل از دکمه بازگشت فیزیکی و ژست لمسی سیستم اندروید (`BackHandler`) بدون بسته شدن ناخواسته برنامه.
  - تمرکز گزارش تحلیل تسلط در بخش سوابق بر جدول‌های ۳ تا ۹.

## تغییرات نسخه جدید (v1.2.0):
- **تنظیم آیکون و لوگوی اختصاصی:** تصویر کارتونی و کودک‌پسند ارائه‌شده با رزولوشن‌های استاندارد اندروید (mdpi تا xxxhdpi) به همراه نسخه دایره‌ای (Round Icon) برای نمایش روی گوشی و صفحه اصلی برنامه پیاده‌سازی شد.
