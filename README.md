# قهرمان جدول ضرب (Zarb Hero)

اپلیکیشن کامل، آفلاین و کودک‌پسند برای آموزش و سنجش جدول ضرب اعداد ۱ تا ۱۰ ویژه کودکان ۹ تا ۱۲ سال به زبان فارسی.

## ویژگی‌ها:
- چیدمان راست‌چین (RTL) و ارقام فارسی
- آزمون‌های استاندارد ۲۰ سؤالی بدون سؤال تکراری و معادل
- الگوریتم تطبیقی وزن‌دهی به سؤالات دشوار
- پایگاه داده محلی و ماندگار (Room)
- کارنامه تفصیلی و تحلیل تسلط جدول‌ها
- ساخت خودکار APK از طریق GitHub Actions

## ساخت خودکار در GitHub:
فایل‌های این پروژه را درون یک مخزن در GitHub بارگذاری نمایید. پایپ‌لاین `.github/workflows/android-build.yml` به طور خودکار برنامه را کامپایل کرده و فایل نصبی APK را در تب Actions به عنوان Artifact برای دانلود قرار می‌دهد.
